ToolkITEveryday network utilities, offline · Getting started

What is ToolkIT?

One page in your browser with the small network tools we reach for every day: a subnet calculator, IP list cleanup and summarizing, VLAN lists, MAC vendor lookup, and generators for fake IPs, MACs and hostnames. It runs on your own laptop and works without internet.

The problem it solves. Jobs like "what's the wildcard for a /22?", "which VLAN IDs are still free on this core?", "summarize these networks for an ACL" or "who made this MAC?" usually mean a different website each time. That's slow, it means pasting work data into someone else's site, and it doesn't work at sites with poor internet. ToolkIT does all of them in one place, offline, in seconds.

Getting started

  1. Extract the zip to a folder you own, e.g. Documents\ToolkIT. Right-click the zip → Extract All…. Don't run it from inside the zip.
  2. There's nothing to set up: no install, no settings, no accounts.
  3. Double-click run.bat. A black console window opens, and then your browser opens at http://127.0.0.1:8780. Keep the console window open while you use it; closing it stops the app.
  4. Once, for the OUI lookup: open the OUI lookup tab and click Update from IEEE at the bottom. It downloads the official MAC vendor list (about 5 MB, a few seconds). After that, lookups work offline. Click it again now and then for a fresher list.
The first time you run it, Windows may show "Windows protected your PC" because run.bat came from a zip. Click More info → Run anyway. If your laptop doesn't allow that, right-click the zip → Properties → tick Unblock → OK, then extract it again.
Tip: bookmark http://127.0.0.1:8780. Adding ?tab=subnet, ?tab=vlan, ?tab=oui (and so on) to the address opens that tab directly. The bookmark only works while run.bat's window is open.

Using it

Every tab works the same way: type or paste into the box, click the blue button, and the result appears underneath. Every result has Copy (to the clipboard) and Download .txt buttons. Clear empties just that tab. Tabs keep their results while you switch between them.

Why the IP list summary can look odd

The Summarized for ACLs / prefix lists box gives the fewest blocks that cover exactly your addresses, never one address more, which is what an ACL or prefix list needs. Blocks have to be a power of two in size (1, 2, 4, 8, 16… addresses) and start at a multiple of their size, so the gaps between scattered addresses can't be bridged:

192.0.2.8 – .15   (8 addresses, starts at a multiple of 8)  →  192.0.2.8/29     one block
192.0.2.5 – .12   (8 addresses, starts at .5)               →  .5/32  .6/31  .8/30  .12/32

So a list of individual devices (for example, the management IPs in use in one subnet) comes out as many small /32, /30, /29 blocks. That's correct for an ACL that must allow only those hosts. To see the one network they all sit in, look at All fit in (one block) instead, which also says how many unused addresses it includes.

Keeping things safe

  • ToolkIT only listens on your own laptop (127.0.0.1); nobody else on the network can reach it.
  • Nothing you paste is saved or sent anywhere. The only thing that uses the internet is the Update from IEEE button, which downloads IEEE's public vendor list.
  • The Hostname faker forgets everything after each paste. The same real name only gets the same fake within one paste, so fake everything that belongs together in one go.
  • If you pass ToolkIT on, share the original zip.

Updating to a new version

  1. Close the app (close its console window).
  2. Extract the new zip to a new folder.
  3. Optional: copy the data folder from the old folder into the new one to keep your vendor list. Otherwise just click Update from IEEE again in the new version.
  4. Run the new run.bat. Once it works, delete the old folder.

If something goes wrong

What you seeWhat to do
The console window flashes and closes, or shows an errorMake sure you extracted the whole zip and are running run.bat from the extracted folder. Send a screenshot of the console to whoever gave you the app.
The browser doesn't openOpen http://127.0.0.1:8780 yourself while the console window is open.
An error in the console saying "only one usage of each socket address" (error 10048)ToolkIT is already running in another console window. Use that one, or close it first.
The page says "This site can't be reached"The console window was closed, which stops the app. Double-click run.bat again.
Update from IEEE says it couldn't reach IEEEYour network may be blocking it. In your browser, download these three files: https://standards-oui.ieee.org/oui/oui.csv, https://standards-oui.ieee.org/oui28/mam.csv, https://standards-oui.ieee.org/oui36/oui36.csv. Then on the OUI lookup tab, choose each one with Import file.
OUI lookup says there's no vendor list yetClick Update from IEEE at the bottom of the OUI lookup tab (once).
OUI lookup says the vendor list couldn't be readA file in the list is damaged or locked. Click Update from IEEE (or Import the files again) to replace it. The other tools keep working meanwhile.
Update or Import says it couldn't saveToolkIT can't write to its own folder (a protected folder, a full disk, or antivirus holding the file). Move the ToolkIT folder somewhere you can write to, such as Documents, and try again.
A MAC says "Locally administered"That's not an error: the address was made up by software (phones and laptops use random "private" MACs), so no vendor owns it.
Lines are listed as "skipped"Those lines weren't addresses, networks or VLANs (e.g. a heading or a port number). Everything else is still processed.
The Copy button says Press Ctrl+CYour browser blocked the clipboard, so ToolkIT has selected the text for you: press Ctrl+C to copy it.

ToolkIT runs entirely on your laptop with its own built-in Python; nothing needs installing.
